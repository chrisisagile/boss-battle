# Aspire AppHost

This AppHost runs the local full stack for the repository:

- self-hosted Convex backend and dashboard via Docker Compose
- a Convex code-sync watcher against that self-hosted backend
- the TanStack app on an Aspire-assigned local port

## Run locally

```bash
pnpm dev
```

Direct AppHost invocation still works:

```bash
aspire run --project devops/AppHost.csproj
```

On first run, the AppHost will:

1. download the upstream Convex self-hosted `docker-compose.yml` into `devops/convex/`
2. `docker compose pull`
3. `docker compose up`
4. generate a self-hosted Convex admin key
5. write `devops/convex/.env.self-hosted.local`
6. start `pnpm exec convex dev` against the self-hosted backend
7. start the frontend Vite watcher on an Aspire-assigned port, with `VITE_CONVEX_URL` derived from the Convex backend endpoint

## Publish and deploy

The AppHost adds a deployment pipeline step that runs:

```bash
pnpm exec convex deploy --yes --cmd "pnpm run deploy" --cmd-url-env-var-name VITE_CONVEX_URL
```

The pipeline derives the self-hosted backend URL from the Convex layer contract
and reads the self-hosted admin key from `devops/convex/.env.self-hosted.local`.
That file is generated by the Convex sync layer during `pnpm dev`, then written
into a temporary env file for `convex deploy` and `wrangler deploy`.
