# Project Context

This wiki holds durable knowledge agents should use across tasks and workflows. Keep guidance concise, current, and safe to share with every configured harness.

- **prompts**: reusable instructions and working agreements.
- **standards**: coding, review, security, and operational expectations.
- **architecture**: system boundaries and durable decisions.
- **docs**: product and domain references.
- **memory**: compact lessons worth carrying into future work.
